内网快传 LanDrop 1.0.0
========================================

Windows 与 Android 在同一个局域网内互传文件，不经过任何服务器。

一、快速上手
------------
1. 电脑与手机连同一个 WiFi / 同一个路由器。
2. 打开手机上的「内网快传」，保持屏幕亮着。
3. 电脑上打开「内网快传」，左侧会在几秒内出现手机名字。
4. 电脑 → 手机：把文件或文件夹直接拖进窗口，或点「发送文件」。
5. 手机 → 电脑：在手机上进入「文件」页，勾选项目后点底部「发送到 …」。

二、接收文件的去向
------------------
电脑：先下载到临时目录（%LOCALAPPDATA%\LanDrop\tmp），完成后移动到
      「下载\LanDrop」，在列表里可以「打开 / 所在文件夹 / 另存为…」。
手机：保存到「下载/LanDrop/」，按原来的文件夹结构排列。

三、第一次接收会弹确认
----------------------
在手机上点「接收」后会记住这台电脑；电脑端勾选「信任的设备自动接收」
后不再询问。信任列表可在两端设置里清空。

四、看不到对方怎么办
--------------------
1. 确认手机端应用在前台、屏幕亮着（熄屏后 WiFi 会丢弃广播，系统限制，无法绕过）。
2. 确认电脑网络类型不是「公用网络」，否则点窗口右上角的提示按钮切换。
3. 确认 Windows 防火墙已放行（安装包会自动加规则；绿色版首次运行会提示，
   也可在设置里点「修复防火墙规则」）。
4. 路由器如果开了「AP 隔离 / 访客网络」，两台设备互相不可见，需要关掉。
5. 还有问题可看日志：%LOCALAPPDATA%\LanDrop\logs\landrop.log

五、端口
--------
UDP 47820 设备发现
TCP 47821 文件传输与网速测试

六、系统要求
------------
Windows 10 1809 及以上 / Windows 11，仅 64 位。
Android 8.0 及以上，需要授予「所有文件访问」权限才能浏览并发送任意文件。
